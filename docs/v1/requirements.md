# TalkToAI Android V1 需求基线

状态：已确认；日期：2026-09-04；Owner：Jerry。

## 最小闭环

用户无需登录即可输入问题，应用保存会话并通过 CloudBase 测试后端流式返回 AI 内容。用户可以停止生成、失败重试、重启恢复，并看到无网络、来源引用和行情新鲜度状态。

## V1 范围

- Android；Kotlin；Kuikly；MVVM 单向数据流；系统浅色/深色主题。
- A 股代码/名称查询、行情摘要、分时图、日/周/月 K 线、自定义日期范围、同步成交量。
- 图片、CSV、TXT 附件；文本选择、复制和会话导出。
- 本机会话创建、重命名、删除、归档、重启恢复。无登录条件下不承诺跨设备同步。
- 插件式只读 AI 工具菜单及状态展示；V1 内置行情查询工具，不允许交易工具。
- 脱敏日志中心与问题反馈包；日志保留 10 天，每日最多 5000 条。
- 每个匿名安装每日最多 500 次 AI 请求，按 Asia/Shanghai 自然日重置。

## 明确排除

- 登录注册、真实跨设备同步、港股、美股、证券开户、持仓管理、下单、支付、生产部署和应用商店发布。
- 确定性买入/卖出指令或收益承诺。回答必须展示“仅供信息参考，不构成投资建议”。

## 外部边界

- AI：CloudBase HTTP AI 接口，模型配置由测试后端环境变量提供，客户端不得持有服务端 API Key。
- 行情：生产接入三狐量化前必须取得可验证的数据使用授权；开发和测试使用固定夹具，可选 AKShare 仅作开发补充。
- 所有客户端远程访问均为 HTTPS；外部提供方由 CloudBase 后端代理和归一化。

## 首版验收

1. 冷启动可进入会话页；断网时明确提示且不丢失草稿和历史。
2. 发送消息后展示流式增量；停止后保留已生成内容；失败可重试且不重复用户消息。
3. 强制结束并重启后，会话、消息、归档和草稿按设计恢复。
4. 查询固定 A 股夹具可切换分时、日、周、月、自定义区间，价格图与成交量共用时间轴。
5. 行情始终展示来源、数据时间、抓取时间和新鲜度；过期数据不得标成实时。
6. 图片/CSV/TXT 可选择、校验和展示；不支持类型、超限和读取失败有可恢复错误。
7. 达到服务端日限额返回稳定错误码和次日重置时间。
8. APK 可安装到指定 Android Studio 模拟器并完成关键路径验证。
